# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-21

### Added
- **Initial release of the GLS Bug Bounty Platform.**
- Secure Capture-The-Flag (CTF) environment built on Flask and SQLite.
- Participant Dashboard for filtering and viewing challenges.
- Real-time flag validation engine with instant feedback.
- Automated hint delivery system with configurable point deductions.
- Live Leaderboard with dynamic real-time scoring.
- Advanced progression logic (prerequisite challenges to unlock advanced tasks).
- Comprehensive Admin Console for full platform management (`/admin`).
- User management controls including ban/unban capabilities and direct password resets.
- Challenge management with full CRUD operations.
- Global "Go Live" visibility controls and granular category staging.
- Automated data export reporting tool (`scripts/create_docx.py`).
- Scripts for bulk user importing and database resetting.
- Cloud deployment documentation and architecture for Oracle Cloud Free Tier.
- Added official GNU GPL v3 Open Source License and headers.
